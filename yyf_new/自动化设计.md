## 方案分析

### 核心问题

Jetson AGX Orin 的 GPIO 引脚特性：
- **所有40pin扩展头 GPIO 只能是 3.3V 输出**（无法直接输出1.8V）
- 3.3V 和 5V 电源引脚是**固定电压**，无法软件调节

因此，需要通过 **GPIO 控制外部电路** 来实现 1.8V 可调电压输出。

| 方案 | 原理 | 精度 | 复杂度 | 推荐程度 |

### 方案1：详细设计（MCP4725）

#### 硬件连接

```
Jetson AGX Orin                          MCP4725 (DAC)
─────────────────                        ──────────────
Pin 27 (I2C1_SDA)  ─────────────────────► SDA
Pin 28 (I2C1_SCL)  ─────────────────────► SCL
Pin 2  (5V)       ─────────────────────► VCC
Pin 6  (GND)      ─────────────────────► GND
                                         │
                                         ▼ OUT (0~3.3V模拟电压)
                                         │
                                    ┌────────────┐
                                    │ 电压跟随器  │ (如 LM6181)
                                    │ (缓冲/放大) │
                                    └─────┬──────┘
                                          │

```

#### Python 控制代码思路

```python
import smbus
import time

# MCP4725 I2C 地址 (典型)
DAC_ADDRESS = 0x60

def set_voltage(voltage_v, vref=3.3, max_voltage=1.8):
    """设置输出电压"""
    # 限制最大输出
    if voltage_v > max_voltage:
        voltage_v = max_voltage
    
    # 12位DAC: 0-4095 对应 0-Vref
    dac_value = int((voltage_v / vref) * 4095)
    
    # 发送命令 (MCP4725 Fast Mode)
    high_byte = (dac_value >> 8) & 0x0F
    low_byte = dac_value & 0xFF
    
    bus = smbus.SMBus(1)  # I2C1
    bus.write_i2c_block_data(DAC_ADDRESS, high_byte, [low_byte])

# 使用示例
set_voltage(1.8)  # 输出 1.8V
time.sleep(1)
set_voltage(1.5)  # 输出 1.5V
```

## 硬件方案

│                                                                     │
│  Pin 15 (GPIO433) ──►  1.8V 电源 EN  ────►  LDO EN               │

                    │                 │

                    └────────┬────────┘

                    ┌─────────────────┐

                    └─────────────────┘

## 为什么"减法电路"不适合供电

    def _terminate_proc(self, proc: subprocess.Popen, tag: str, force=False):
        if proc is None:
            return
        if proc.poll() is not None:
            self._log(f"[SYS] {tag} 已退出 (code={proc.returncode})")
            return
        try:
            sig = signal.SIGTERM if force else signal.SIGINT
            os.killpg(proc.pid, sig)
            self._log(f"[SYS] 已发送 {sig.name} 到 {tag}")
            proc.wait(timeout=8)
            self._log(f"[SYS] {tag} 已退出 (code={proc.returncode})")
        except subprocess.TimeoutExpired:
            self._log(f"[WARN] {tag} 未响应，准备强制终止...")

        except Exception as exc:
            self._log(f"[ERR] 终止 {tag} 失败: {exc}")
